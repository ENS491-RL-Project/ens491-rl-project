# GRU-Based Task Identification: Experimental Validation

## Overview

Candidate 1 (Recognition Track R-2) focuses on supervised GRU-based task identification from observation sequences generated by pretrained PPO policies in MiniGrid.

The supervised known-task identification and sequence-length ablation experiments have been completed.

## Methodology

- **Dataset:** 5,500 episodes collected from 11 pretrained PPO policies.
- **Classification:** 9 task classes, with related PPO policies mapped to shared task labels.
- **Input:** Observation-only sequences (147-dimensional observations).
- **Model:** Single-layer GRU with hidden size 64.
- **Evaluation:** Episode-disjoint training, validation, and test splits.
- **Ablation:** Sequence lengths of 1, 5, 10, 20, and 50 observations.

## Results

| Metric | N=1 | N=5 | N=10 | N=20 | N=50 |
|---|---:|---:|---:|---:|---:|
| Window accuracy | 53.10% | 79.08% | 80.40% | 74.70% | 79.60% |
| Task-episode macro accuracy | 62.51% | **83.55%** | 81.56% | 79.45% | 81.91% |
| Episode-balanced accuracy | 58.13% | **81.42%** | 80.64% | 77.82% | 80.93% |

## Key Findings

1. Observation histories substantially improve task identification compared with single observations.
2. N=5 achieved the highest task-episode macro accuracy (83.55%).
3. N=10 achieved the highest window-level accuracy (80.40%).
4. Composite tasks such as `unlock` remain challenging to distinguish from related primitive tasks.
5. Longer sequences do not consistently produce better overall classification performance.

## Completion Status

**Completed:** Supervised GRU training, held-out evaluation, confusion-matrix analysis, and sequence-length ablation.

**Not yet evaluated:** Task-switch recognition latency, old-task retention during sequential task introduction, and end-to-end AE–GRU integration.

These results establish the supervised task-identification baseline for subsequent integration with the continual and hierarchical RL architecture.
